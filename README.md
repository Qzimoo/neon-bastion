NEON BASTION — an original neon arena survival shooter written in vanilla JavaScript on Canvas 2D. Pilot your ship with WASD + mouse, hold to shoot, dash through danger with i-frames, chain kill combos up to ×5, survive escalating waves with four enemy types plus an elite every five waves, and chase the high score. Synthesized WebAudio sound effects and a 132 BPM loop, title / pause / game-over flow, and a persistent best score — all in one static page with zero network requests.

## Run it

```sh
# No build step. Serve the game folder and open it in any modern browser:
python3 -m http.server -d game 8000
# then visit http://localhost:8000
```
